Сетевой протокол — набор правил, позволяющих осуществить соединение и обмен информацией между двумя и более включёнными в сеть устройствами.

IP-адрес — это 4 числа от 0 до 255, разделённые точками.

DNS — Domain Name System

Доменная система имён: чтобы не запоминать числовые IP-адреса, сайтам дают символьные имена.

Доменное имя — уникальное символьное имя сайта (компьютера) в Интернете, удобное для человека. Состоит из доменов, разделённых точками.

DNS-сервер преобразует доменное имя в IP-адрес.
  1. Браузер отправляет запрос DNS-серверу, чтобы получить IP-адрес сайта.
  2. Ожидает ответа — DNS-сервер сообщает IP-адрес.
  3. Запрашивает веб-страницу по полученному IP-адресу.

Домены 1-го уровня утверждает ICANN; домены 2-го уровня в зоне .kz регистрирует KazNIC; домены 3-го уровня создаёт владелец домена 2-го уровня.

Устный опрос (нажми, чтобы увидеть ответ)

1. Зачем нужна доменная система имён?Чтобы людям не нужно было запоминать числовые IP-адреса: у сайтов появляются удобные символьные имена.
2. Что делает DNS-сервер?Преобразует доменное имя в IP-адрес.
3. Назовите домен второго уровня в имени 1-semey.mektebi.kzmektebi (уровни считаются справа налево: kz — 1-й, mektebi — 2-й, 1-semey — 3-й).
4. Чем отличается HTTPS от HTTP?HTTPS передаёт веб-страницы с шифрованием данных.
5. Какой протокол используют для передачи файлов?FTP (File Transfer Protocol).
6. Почему сайт открывается по имени, даже если его перенесли на сервер с другим IP-адресом?Владелец меняет запись в DNS: имя осталось прежним, а DNS-сервер теперь выдаёт новый IP-адрес.
